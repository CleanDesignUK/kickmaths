# KickMaths

Train Your Brain. Win the Game.

Primary maths game and curriculum website for UK families and schools. The Year 1–6 map follows England’s National Curriculum. Copied from CleanDesignUK/primary-uk-maths with its complete commit history preserved; the original repository is unchanged.

## Development

- `npm run check`: module syntax.
- `npm run build`: generate the 34 public pages, sitemap and metadata.
- `npm test`: learning, rewards, written methods, reports, paid customisation and launch-site checks.
- `npm run build:worker`: package the optional Worker deployment.
- `npm run dev`: development preview only.

The game is in `dist/play/`. Marketing copy is generated by `scripts/build-marketing.mjs`; edit that source before rebuilding. Public styles and cookie/reading controls are in `dist/marketing.css` and `dist/marketing.mjs`.

## Publishing

`Publish KickMaths` builds, tests and deploys `dist/` with GitHub Pages. The Pages source must be GitHub Actions. The public repository URL is https://cleandesignuk.github.io/kickmaths/ once deployment succeeds. Canonical URLs and the sitemap use the intended domain https://kickmaths.co.uk. Do not add a CNAME redirect until domain DNS is connected and verified.
